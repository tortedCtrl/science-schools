# Инструкции для агента

## Проект
- Общее описание проекта и запуск — в [README.md](README.md).
- Платформа исследует связи и сообщества учёных на основе библиографических данных; продуктовые требования описаны в [docs/PRD.md](docs/PRD.md).
- Направления и этапы работ — в [docs/ROADMAP_45_DAYS.md](docs/ROADMAP_45_DAYS.md).
- Backend — C++ API и вычислительный модуль; frontend — React и TypeScript.
- Алгоритмические сообщества — аналитические гипотезы, а не подтверждённые научные школы. Не добавляй оценки компетентности учёных и не делай персональных выводов о миграции.

## Работа с кодом
- Не меняй стиль существующего кода без прямого требования; придерживайся локальных соглашений и современных рекомендаций используемого стека.
- Ограничивай изменение минимально необходимыми файлами и сохраняй существующее поведение.
- Не храни секреты в коде и не раскрывай их в логах.
- Перед завершением запускай относящиеся к изменению проверки и исправляй вызванные изменениями ошибки.
