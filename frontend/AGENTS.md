# Frontend (React + TypeScript)

- `src/api` содержит API-клиент, `src/hooks` — хуки для данных и состояния, `src/components` — UI-компоненты.
- Используй существующие компоненты в `src/components/`, хуки в `src/hooks/` и API-клиент в `src/api/`; не меняй архитектуру без необходимости.
- Сохраняй строгую типизацию, доступность интерфейса и явные состояния загрузки, ошибки и пустого результата.
- Не форматируй и не переоформляй чужой код без прямого требования; ограничивай изменения минимально необходимыми файлами.
- Проверки: `npm run lint` и `npm run build` из `frontend/`. Отдельного тестового скрипта в проекте сейчас нет.
